THE MACHINE ROOM — UNDER THE CASE

The Machine

What's inside DieselOS, and the discipline that keeps it honest: snapshot before big work, every long job writes a verdict file, and nothing is "done" until the file says so.

THE PROFILE

A guest that earns its keep

The image

One disk image, built from a recipe the studio keeps: Ubuntu 24.04 with the development manifest baked in — 377 packages at first proof, including the SDL3 stack the games build against. The image is the machine; lose the host and the image is reborn from the recipe, not from memory.

The snapshots

Before any big change, the machine takes a named snapshot (the current working one is the second dev-home snapshot). A failed experiment is a rollback, not a rescue mission — which is how the OS stays a safe place to try things at 3 AM.

THE TOOL BATCH

Small tools, sharp edges

djob

Long builds and test batteries run detached and leave a verdict file when they finish — pass or fail, in writing, whether anyone was watching or not.

dsnap

One command to snapshot the whole machine before risky work, and one to roll back. Cowardice, automated.

ccache

A compiler cache, because a full rebuild of a big game inside a guest is slow enough the first time.

The canary

An uptime watcher that notices when the host floor disappears from under the guest — so a vanished machine is a known event, not a mystery.

The studio's rule, built into the machine: a test that leaves no file never happened.
THE TEST ROUTE

Where verdicts come from

Built on the host, proven on the rig

AirportSim is developed on the host, and its full test batteries — tens of thousands of checks — run on Andrew's own self-hosted rig. DieselOS is the workshop Diesel lives in; the proving happens on the rig, and the records say so plainly.

Honest limits

The host environment restarts the guest every couple of hours — the cause sits outside the machine room, so the page doesn't invent one. The design answers it instead: snapshots, detached jobs with verdict files, and work that resumes where it stopped.
