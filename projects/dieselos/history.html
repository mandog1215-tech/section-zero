THE MACHINE ROOM — THE LINEAGE

First, Bare Metal

DieselOS began as something more stubborn: GROUNDTRUTH, an operating system written from scratch — its own kernel, its own everything. It was scrapped and revived inside a single November day, and then it did the smartest thing a young OS can do: it became useful.

BORN 2026-11-10 NAMED BY ANDREW UBUNTU EDITION WON THE BENCH
THE PIVOT

One day, two operating systems

The bare-metal line

GROUNDTRUTH was the from-scratch road: a custom kernel and a math-based system, built stage by stage with proofs at every gate. It reached a working login gate on bare metal. That line is frozen, not deleted — its repository and records are kept, and the discipline it taught (prove everything, in writing) runs the studio to this day.

The Ubuntu turn

The same day it was revived, Andrew aimed it: "a math based custom Ubuntu for our needs." The core became Ubuntu — mature plumbing where nothing was gained by rewriting it — and the custom work moved to where it mattered: the Face, the tools, the test route. Andrew named the result: first StudioOS, then, better, DieselOS.

THE PROOFS

Phases, in order, in writing

Phase A — 2026-11-12

First boot proof: the image boots clean, zero kernel panics, the development manifest inside — 377 packages, SDL3 among them.

Phase B — 2026-11-12

The Face: the studio's own splash, a real login, and a home screen — Diesel's programs standing where a stock desktop would be.

Phase C — 2026-11-12

AirportSim moves in: the game builds and its batteries run inside the guest. The machine room has a tenant.

Batch 1 — 2026-11-13

The tool batch lands — djob, dsnap, ccache, live project state, the uptime canary — and a fresh snapshot seals the machine as the dev home.

Every phase above closed with evidence first and adjectives after — the bare-metal line's one inheritance that never froze.
