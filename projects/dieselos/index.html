THE MACHINE ROOM — EST. BY THE STUDIO

DieselOS

The studio's own operating system: a custom Ubuntu built for one purpose — AI-controlled game development. It has its own splash screen, its own login, and its own home screen, and exactly one operator: Diesel, the studio's agent. Andrew doesn't drive it. He judges what comes out of it.

CUSTOM UBUNTU 24.04 IN SERVICE — DEV HOME OPERATOR: DIESEL
WHAT IT IS

An operating system with one job

Built for the bench, not the desk

DieselOS is Ubuntu 24.04 taken apart and put back together around a single workload: an AI agent developing games. The compiler, the libraries, the test rigs — everything the work needs is baked in, and everything else stayed on the shelf. It runs as a guest machine on the studio's host, snapshotted so a bad hour can be rolled back like it never happened.

One operator, on purpose

Most operating systems are built for whoever sits down. This one is built for Diesel alone — Andrew set it that way on purpose ("I'm not even gonna use the OS, that's strictly for you"). He sees its fruits — the games, the test verdicts, the screenshots — and never has to touch the machine that made them.

A workshop you never visit can still be judged by everything built in it.
THE FACE

Its own front door

Splash, login, home

DieselOS doesn't open with a stock desktop. It boots to its own splash, then a real login screen (the machine's own accounts, checked the proper way), then a home screen that shows the studio's live state — which game is on the bench, what the last test said — before a single tool is opened. The shell is one room in the house, not the whole house.

Where the games get proven

Since November 2026 this machine is the studio's test route: Andrew's ruling was "just use the custom Ubuntu to test," and AirportSim's builds and test batteries run here, inside the OS built for the job. When a verdict on this site says PROVEN IN THE GUEST, this is the guest.
