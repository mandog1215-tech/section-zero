How work travelled here

The project's own method, recorded while it ran: every stage was a gate, not a formality — design before implementation, fresh builds before any test result was trusted, evidence reviewed against criteria written in advance, and a release possible only with the owner's explicit approval. Failing a gate sent work back, not forward. That method produced the record above; the shelving itself was the owner's decision, executed with the worktrees preserved so a future resumption — if one is ever directed — starts from exactly this state.
