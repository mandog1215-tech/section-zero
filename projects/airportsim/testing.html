AIRPORTSIM — FIELD NOTES

How an Airport Earns Its Stripes

Nothing merges on a promise. Proof here runs on public machines in four lanes — and then a camera cross-examines everything the lanes cannot see.

The four lanes

A full test suite whose checks run into the hundreds of thousands; two memory-safety batteries that shadow the program's allocations and pounce on the quiet corruptions; and a static analysis pass that reads the code the way a sceptical auditor reads accounts. A change runs all four, and the results are read lane by lane, at the source.

The identity safeguard

The code that merges must be the very code that was tested — same commit, bit for bit. If a branch so much as twitches after its battery has run, the battery runs again. It is the studio's most pedantic rule and its most load-bearing one.

The camera's turn

Tests cannot see a jet bridge stopping short of a door, or a sign too faint to read at approach speed. So the game is photographed on a schedule — wide frames for the scene, tight crops for the detail under judgement — and the photographs are inspected, by eye, before the verdict is written down.
