Public-build policy (owner, 2026-11-03)

The game is not planned for public sale or release: its next major milestone is a closed dev beta, 7.0 “Latitude” — a private test build for the owner's hands-on, internal testing only (in development, 2026-11-07). Any copy that does leave the studio is a private one, and it ships under two standing rules the owner set on 2026-11-03:

  • Copy protection in place. Protection here is provenance, not a gate: the studio's credits and copyright in the game, the binary and the data, and a unique invisible fingerprint on each copy handed out — so a copy's origin can always be shown. There is no license-key gate and nothing phones home; heavy protection that punishes honest players would fail the owner's standard.
  • No source code in public builds. Packages will contain compiled binaries and game data only — never source files — and the package contents will be verified against that rule before anything goes out.

Nothing public ships until both rules are met. The held builds above are unaffected: they were never public, and they stay held.

The rules that keep this page honest

  • A build is a release only when recorded in a registry with its exact commit or tag, its evidence, and its status.
  • HELD is a first-class status, recorded in plain words — never omitted to make a project look further along.
  • No status changes without evidence on the exact commit; no release happens without the owner's explicit approval.
  • Public packages ship compiled binaries and game data only — no source code — with copy protection in place and the contents verified before anything goes out (the owner's public-build policy, 2026-11-03).
