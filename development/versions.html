DEVELOPMENT — THE RECORD ROOM

The Version Ledger

A version number is a claim about state, so this studio keeps them in a ledger like everything else. Four worlds, four numbers, four quite different meanings.

WildGenesis 3D — 0.6.3

The studio's active game: a god-game evolution sandbox being restructured — the same game and the same systems, rebuilt cleanly, slice by slice. The new structure and the bug-catching gate are done and proven; the pure core is being extracted next. Each slice is proven against the same 48-check battery before the next begins.

AirportSim — 7.0 'Latitude'

The closed test copy of the studio's airfield game, delivered to the owner on 17 November 2026 and awaiting his verdict. The deepening list is halted until he speaks; its finished identity remains his to bestow at the handover.

Blacksite — 1.5.0

An unfinished game under a closed file. No release has been called and none is coming: 1.5.0 is simply where the shooter stopped, and the stall is indefinite.

WorldForge — 0.5.0-dev

The development line of an unfinished, parked game. A 1.0.0 candidate is held in the project records, but the owner has not called WorldForge finished and nothing has been released; the number the finished game will wear is the owner's to say.
